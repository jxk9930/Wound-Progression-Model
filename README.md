# Wound-Progression-Model

This model can be used to estimate wound progression, especially in diabetic foot ulcers. All equations are based on biomechanics. This model was used for the Texas Healthcare Challenge (TXHCC).
My wound progression model utilizes the following pre-trained models as inputs:

    Image Classification: dqnguyen/Diabetic_Foot_Ulcer_Image_Classification

    Foot Segmentation: roboflow/Foot Segmentation Computer Vision Model

    Ulcer Segmentation: masih4/Foot_Ulcer_Segmentation
